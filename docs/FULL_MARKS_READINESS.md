# Excellent-Band Readiness Checklist

The software has been structured to address the assessment's Excellent-band features. A mark cannot be guaranteed because grading also depends on the submitted report, genuine Git history, screenshots, explanations and examiner judgment.

## Task A — UML (20)
- detailed use case diagram with correct actors
- `<<include>>` and `<<extend>>`
- class diagram with private/public members, multiplicities and composition
- at least three sequence diagrams with lifelines/messages/alternatives
- documented assumptions and design justification
- report must critically explain why diagrams match the implementation

## Task B — Program / architecture / patterns (40)
- Java 21 Spring Boot application
- sophisticated responsive UI
- three-tier architecture
- MVC, Repository, Service Layer and Strategy patterns
- distributed REST billing web service
- proper MySQL/MariaDB relational database
- advanced view/procedure/function/triggers
- useful decision-making reports + CSV export
- authenticated sessions/cookies and role authorization
- appointment reminder alerts and billing-service health monitoring
- validation, overlap prevention, audit trail and robust error handling

## Task C — Testing (20)
- JUnit/Mockito business-rule tests
- REST endpoint validation test
- Spring context integration test
- role authorization integration test
- H2 isolated test profile
- GitHub Actions test automation
- JaCoCo coverage reports
- requirements traceability and manual test plan
- student must capture real RED/GREEN/REFACTOR and passing-test screenshots

## Task D — Git/GitHub (20)
- public repository required by brief
- incremental commits over multiple development stages
- feature/develop/main branching evidence
- pull request/merge evidence
- CI workflow evidence
- version tags and GitHub Releases with packaged JARs
- latest runnable version demonstrated in report

## Evidence that must come from the student
Do not fabricate these:
- real GitHub URL/history/dates
- actual workflow run screenshots
- actual test result screenshots
- actual XAMPP/phpMyAdmin screenshots
- actual UI screenshots
- actual deployment/release screenshots
- personal critical evaluation and lessons learned
