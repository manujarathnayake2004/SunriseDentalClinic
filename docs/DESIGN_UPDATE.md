# Dental Blue/Cyan Design

The interface uses a modern clinical blue/cyan visual system while preserving the functional requirements of the Sunrise Dental Clinic scenario.

## Main frontend files
- HTML / Thymeleaf pages: `clinic-app/src/main/resources/templates/`
- Main CSS: `clinic-app/src/main/resources/static/css/theme.css`
- Images: `clinic-app/src/main/resources/static/images/`
- Login image: `clinic-app/src/main/resources/static/images/dental-hero.png`
- Dashboard image: `clinic-app/src/main/resources/static/images/dashboard-hero.png`

## Interface design
- White and soft-aqua content backgrounds
- Dark dental-teal navigation sidebar
- Cyan active states and primary actions
- Consistent cards, tables, forms, validation messages and status badges
- Responsive layout for smaller screens
- Printable receipt layout
- Clear separation between staff operations and administrator-only configuration
